# Tawjihi Together

**Study smarter. Learn together.**

A student-led initiative sharing free interactive study resources for friends, classmates, and Jordanian Tawjihi students.

This repository is being initialized. The complete project bundle is included as `project-bundle.zip`; GitHub Actions will expand it into the site files after the first push.

## Current resources

- English — Unit 3: Hard Sell Drill
- Geology — Unit 3: Geological Structures

The resources are browser-based HTML files. No installation is required.

## How to contribute

Report incorrect answers, unclear explanations, or broken interactions through GitHub Issues. Please respect copyright and do not upload restricted textbook scans or answer keys.

## Project status

Early release. More units will be added as they are reviewed and prepared.

Created by a Jordanian Tawjihi student for students.
