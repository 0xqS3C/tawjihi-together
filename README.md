# Tawjihi Together

**Study smarter. Learn together.**

Tawjihi Together is a student-led initiative to share free, interactive study resources with friends, classmates, and Jordanian Tawjihi students.

## Planned first resources

- **English — Unit 3: Hard Sell Drill:** vocabulary, exercises, grammar, and revision.
- **Geology — Unit 3: Geological Structures:** Arabic explanations, diagrams, questions, and revision tools.

The repository is being set up. The interactive HTML resources still need to be uploaded before these links become available.

## Contribute

Report incorrect answers, unclear explanations, or broken interactions through GitHub Issues. Please respect copyright: do not upload restricted textbook scans or answer keys.

Created by a Jordanian Tawjihi student, for students.
